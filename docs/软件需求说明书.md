## 1. 背景、目标与范围

宿舍智能设备通常具备照明、通风、空调等自动化需求。本项目不连接真实硬件，而是实现“**环境输入 → 规则判定 → 设备动作 → 执行反馈 → 本地恢复**”的业务闭环。用户可创建逻辑规则，调整 Mock 环境，观察规则按优先级执行或被跳过的原因。

本课程版本只包含 **本地单设备模拟**。不实现蓝牙、分布式设备连接、云端同步、账号与服务器。适配 Stage 模型、ArkTS + ArkUI，存储采用 Preferences。

## 2. 用户故事和操作闭环

用户进入“环境演练”读取本地存档；切换到“规则管理”，创建“温度≥30℃时开启空调”规则并设置优先级；返回环境页加载“盛夏午后”，点击执行；设备按优先级更新并显示提示；日志页按最新在前展示每次动作，低优先级冲突以“跳过”明确标记。退出应用、从最近任务结束应用进程，再启动恢复之前的环境、设备、规则、日志。

## 3. 核心状态和数据模型

| 数据 | 字段 | 约束 | 生命周期 |
| --- | --- | --- | --- |
| Environment | temperature/humidity/lux:number | 0–40 / 0–100 / 0–1000 | UI @State + Preferences |
| DeviceState | id/name:string; on:boolean | id∈LIGHT,FAN,AC,CURTAIN | UI @State + Preferences |
| RuleCondition | field/operator:string; value:number | 字段和运算符白名单；阈值按字段范围校验 | Rule 子对象 |
| AutomationRule | id/name/enabled/priority/conditions/targetDevice/action | name 1–24字符；priority 1–100；conditions 1或2 | UI @State + Preferences |
| ExecutionLog | id,time,order,ruleId,conditionText,previousOn,nextOn,status,message | status∈APPLIED,SKIPPED_CONFLICT | 最多100条，Preferences |
| AppSnapshot | version/environment/devices/rules/logs/nextRuleId | 版本固定为1 | JSON → Preferences 单键 |

规则生命周期：**创建**（enabled=true）→ **修改**（保持当前 enabled）→ **禁用/启用** → **删除**。规则数据修改不会自动控制设备，必须再次点击“执行演练”，避免编辑表单触发意外动作。

### 3.1 命中与冲突算法

1. 验证 Mock 环境数据范围，不符合范围时中断演练。
2. 对所有规则按 `(priority DESC, id ASC)` 排序。
3. 逐条忽略已禁用或未满足全部条件的规则。双条件采取严格 AND，无 OR。
4. 命中规则且目标设备本轮尚未控制：执行 ON/OFF，记录 `APPLIED`，即使状态本来一致，也记为命中。
5. 同一设备本轮已被更高（或同等且 ID 较小）规则控制：不覆盖，记录 `SKIPPED_CONFLICT`。
6. 返回新设备数组和日志；不原位修改输入设备列表。

**例子**：输入温度33℃；规则A=“温度≥28，风扇开，P90”；规则B=“温度≥28，风扇关，P30”。结果风扇开启，日志顺序为A已执行、B冲突跳过。调整B优先级为95后，重复演练风扇关闭，体现优先级确实影响结果。

## 5. 非功能性要求

- **可维护性**：业务规则引擎不直接依赖 UI/Preferences；用例可直接调用纯函数。
- **持久化可靠性**：使用 `putSync()` 更新缓存 + `flush()` 落盘；读取发生异常时回退初始配置。需要在设备中做杀进程恢复实测。
- **可解释性**：每轮在日志中标识 `order`、触发条件、动作前后值及跳过原因。
- **性能边界**：日志保留100条；本课程面向轻量规则集，不支持百上千条规则或高并发。
- **安全边界**：无账户和网络通信；Preferences 不适合存放敏感信息，当前只保存模拟数据。

## 6. 异常与边界

| 场景 | 对应处理 |
| --- | --- |
| 超过环境范围，例如41℃ | RuleEngine.evaluate 抛错误，页面显示失败提示，不应用状态变更 |
| 条件阈值无效，例如温度50℃ | 保存规则校验失败并弹窗，不改变规则列表 |
| 优先级非整数/超范围 | 拒绝保存 |
| 同设备被两条规则同时命中 | 高优先级先执行，另一条记冲突跳过 |
| 双条件仅一项成立 | 不触发动作，无对应日志 |
| 规则禁用 | 该规则不参与计算 |
| 读取文件损坏 / JSON格式不合法 | load 回退默认业务数据，避免白屏 |
| 记录超过100条 | 仅保留最近100条 |
